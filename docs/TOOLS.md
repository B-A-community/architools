# Инструменты ArchiTools 0.3.1

Все 74 инструментов в 8 категориях — подписи и параметры взяты из самого плагина (пересобирается `python test/make_tools_doc.py`). Для каждого: что выделить и что он делает, нужны ли клики в модели, параметры со значениями по умолчанию и аналог в 1001bit Tools или JHS Powerbar.

Общее для всех: панель «ArchiTools» → категория → инструмент → параметры → «Применить». Каждое применение — один шаг отмены (Ctrl+Z). Длины вводятся в единицах модели. Последние значения параметров запоминаются для каждого инструмента.

## Рёбра и точки

### Скругление

Два ребра в одной плоскости — скругление угла между ними (радиус 0 — просто угол). Цепочка из трёх и более рёбер — скругляются все её углы.

**Аналог:** 1001bit: №11 Fillet

| Параметр | По умолчанию | Варианты |
|---|---|---|
| Радиус | 300 mm |  |
| Сегментов дуги | 12 |  |

### Фаска

Два ребра или цепочка рёбер. Второе расстояние 0 — фаска равносторонняя.

**Аналог:** 1001bit: №12 Chamfer

| Параметр | По умолчанию | Варианты |
|---|---|---|
| Расстояние 1 | 200 mm |  |
| Расстояние 2 | 0 mm |  |

### Продлить до пересечения

Два ребра — продлить или обрезать оба до точки пересечения. Рёбра и одна грань — продлить рёбра до плоскости грани.

**Аналог:** 1001bit: №13 Extend

Параметров нет — всё решает выделение.

### Деление ребра

Рёбра — точки или разрезы: на N частей, с шагом от начала, с шагом от середины, «шаг не больше» (для балясин); можно ставить точки в серединах частей.

**Аналог:** 1001bit: №2 Divide

| Параметр | По умолчанию | Варианты |
|---|---|---|
| Делить | на части | на части, по длине, от середины с шагом, шаг не больше |
| Частей | 4 |  |
| Длина части | 1000 mm |  |
| Результат | разбить ребро | разбить ребро, поставить точки, точки в серединах |

### Точка центра

Дуги и окружности — точка в центре; грани — точка в центре тяжести.

**Аналог:** собственный инструмент ArchiTools

### Смещение рёбер

Цепочки рёбер (не только контур грани). Замкнутый контур смещается наружу, «в другую сторону» — внутрь. Открытая цепочка считается идущей от конца с меньшим X (затем Y): положительное смещение — влево от этого направления. Результат — рёбра или направляющие.

**Аналог:** 1001bit: №14 Offset; JHS Powerbar: Offset Edge

| Параметр | По умолчанию | Варианты |
|---|---|---|
| Расстояние | 100 mm |  |
| В обе стороны | нет |  |
| В другую сторону | нет |  |
| Результат | рёбрами | рёбрами, направляющими |

### Уклон рёбер

Открытая цепочка рёбер — поднять по уклону от нижнего конца (при равных — от конца с меньшим X): угол, 1:N или перепад высоты. «Начать с другого конца» — наоборот.

| Оставить исходные рёбра (уклон — копии) | нет |  |

Грани — линия или направляющая по нормали из центра грани.

### Точка на грани

Одна грань. Кликните опорную точку и направление: точка ставится на заданных расстояниях по направлению и поперёк него (на стене — вверх). Для разбивки: светильник в 600 мм от края на высоте 1800.

**Клики в модели:** после «Применить» укажите точки (подсказка — в строке состояния). Enter или двойной клик — готово, Backspace — убрать точку, Esc — отмена.

**Аналог:** 1001bit: №1 Point on face

| Параметр | По умолчанию | Варианты |
|---|---|---|
| По направлению | 600 mm |  |
| Поперёк (вверх) | 1800 mm |  |

**Клики в модели:** после «Применить» укажите точки (подсказка — в строке состояния). Enter или двойной клик — готово, Backspace — убрать точку, Esc — отмена.

**Аналог:** 1001bit: №4 Perpendicular line

| Параметр | По умолчанию | Варианты |
|---|---|---|
| Результат | ребро | ребро, направляющая |

### Грань на плоскости

Три клика задают плоскость, следующие — контур; каждая точка проецируется на плоскость. Enter или двойной клик — построить грань.

**Клики в модели:** после «Применить» укажите точки (подсказка — в строке состояния). Enter или двойной клик — готово, Backspace — убрать точку, Esc — отмена.

**Аналог:** 1001bit: №5 Face on plane

Параметров нет — всё решает выделение.

### Грань по неплоским точкам

Кликайте точки контура (могут не лежать в одной плоскости) — грань строится по наилучшей плоскости. Enter или двойной клик — готово. Для латания моделей.

**Клики в модели:** после «Применить» укажите точки (подсказка — в строке состояния). Enter или двойной клик — готово, Backspace — убрать точку, Esc — отмена.

**Аналог:** 1001bit: №6 Best fit face

Параметров нет — всё решает выделение.

### Переместить вершину

Ничего выделять не нужно. Кликните вершину, затем новое место — вершина переедет, грани растянутся.

**Клики в модели:** после «Применить» укажите точки (подсказка — в строке состояния). Enter или двойной клик — готово, Backspace — убрать точку, Esc — отмена.

**Аналог:** 1001bit: №10 Move vertex

Параметров нет — всё решает выделение.

### Выровнять по 3 точкам

Группы или компоненты. Три клика — опорные точки на объекте, три — куда они должны встать. Например, машину на склон.

**Клики в модели:** после «Применить» укажите точки (подсказка — в строке состояния). Enter или двойной клик — готово, Backspace — убрать точку, Esc — отмена.

**Аналог:** 1001bit: №3 Align selected entities; JHS Powerbar: Align Tool

| Параметр | По умолчанию | Варианты |
|---|---|---|
| Масштабировать по 1-й паре точек | нет |  |

### Профиль по пути

Грань-профиль и путь — цепочка рёбер или вторая, большая грань (её контур). Профиль можно поставить поперёк пути в его начале — или нарисовать где угодно, например плашмя на земле, как в 1001bit (на земле Y — вверх): тогда он встанет в начало пути низом по центру или центром. Профиль не закручивается на наклонах — остаётся отвесным; вертикаль — по Z, по вектору или по выделенному ребру (как Upright Extruder).

**Аналог:** 1001bit: №7 Extrude along sloping curve path; JHS Powerbar: Upright Extruder, Upright Extruder Input, Upright Extruder Edge, Extrude Along Path

| Параметр | По умолчанию | Варианты |
|---|---|---|
| Вертикаль профиля | по оси Z | по оси Z, по вектору, по выделенному ребру |
| Вверх X | 0 |  |
| Вверх Y | 0 |  |
| Вверх Z | 1 |  |
| Привязка чертежа профиля | низ по центру — на путь | низ по центру — на путь, центр — на путь |
| Сгладить рёбра | да |  |
| Удалить профиль | нет |  |

**Аналог:** JHS Powerbar: Center on Red, Center on Green, Center on Blue

| Параметр | По умолчанию | Варианты |

| Относительно | крайнего объекта | крайнего объекта, самого большого, общего центра выделения |
