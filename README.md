# ArchiTools

Плагин SketchUp 2024 для архитектурного моделирования. Это переосмысление
заброшенного 1001bit Tools, написанное с нуля.

Версия 0.2.0 · лицензия [Apache 2.0](LICENSE) · © 2026 B&A community

Создатели: maksarsanjeev — см. [AUTHORS](AUTHORS)

## Что делает

33 инструмента в шести категориях. У каждого есть панель параметров, а
результат укладывается в один шаг отмены.

| Категория | Инструменты |
|---|---|
| **Рёбра** | Скругление (двух рёбер или всех углов цепочки), фаска, продление до пересечения или до плоскости грани, деление ребра (на N частей или по длине; разбить или поставить точки), точка центра дуги или грани, смещение цепочки рёбер, уклон рёбер (угол, 1:N, перепад), перпендикуляр к грани |
| **Правка** | Выдавить сразу много граней, сдвиг граней по нормали, оболочка (придать поверхности толщину), профиль по пути без закручивания, сечение из библиотеки по пути (круг, трубы, двутавр, швеллер, уголок, тавр), круговой и линейный массивы, выравнивание и равномерное распределение объектов |
| **Стены и проёмы** | Стена по линиям плана (открытые цепочки и замкнутые контуры, привязка по оси, слева или справа), проём в стене (прямоугольный, арочный, круглый — по размерам или по нарисованному контуру; коробка по откосам любой формы), окно (рама, импосты, стекло), дверь (одно- и двупольная) |
| **Фасад** | Ламели (горизонтальные и вертикальные, с шагом и наклоном, по контуру любой грани, нулевая толщина = одна грань), разбивка грани на панели с рамой |
| **Лестницы** | Прямой марш (по плите, сплошной, ступени на косоурах), лестница с площадкой (Г- и П-образная, налево и направо), винтовая, эскалатор (30°/35°); ограждения со стойками, поручнем и балясинами, ригелями или стеклом — у маршей и отдельным инструментом по любым рёбрам. Лестницы ставятся кликом |
| **Каркас и кровля** | Балки перекрытия, стропила, прогоны и обрешётка (все обрезаются по контуру грани), кровля (вальмовая, двускатная, односкатная по прямоугольнику; вальмовая по любому выпуклому контуру через прямой скелет; со свесом и толщиной), колонны (прямоугольные и круглые, с фундаментом), балки по рёбрам любого сечения из библиотеки |

Отказ всегда объясняет причину («Радиус не помещается на рёбрах; наибольший —
612 mm»). Если причина в выделении, плагин пишет, что нужно выделить.

## Управление

- **Панель ArchiTools** (Расширения → ArchiTools → Панель, или первая кнопка
  панели инструментов). Наверху статус показывает, что сейчас выделено. Ниже
  идут вкладки категорий, кнопки инструментов, подсказка «что выделить» и
  параметры. Поля, которые не относятся к выбранному режиму, скрыты. Кнопка
  «Применить» (или Enter в поле) запускает инструмент.
- **Кнопки категорий** на панели инструментов открывают панель на этой
  категории.
- **Пункты меню** Расширения → ArchiTools → <категория> → <инструмент>
  запускают инструмент сразу, с последними параметрами. На них можно повесить
  горячие клавиши SketchUp.
- **Расстановка кликом** для лестниц и одиночной колонны: объект едет за
  курсором с привязками SketchUp. Tab или ←/→ поворачивают его на 90°, клик
  ставит, Esc убирает.
- Длины вводятся в единицах модели: можно писать `1200`, `1,2м`, `4'6"`.
  Параметры запоминаются для каждого инструмента отдельно.

## Чем отличается от 1001bit Tools

| | 1001bit Tools | ArchiTools |
|---|---|---|
| Ввод | Модальные окна на каждый инструмент, указание точек кликами | Одна немодальная панель на всё и работа по выделению; клик нужен только для расстановки |
| Профиль по пути | Свой алгоритм против закручивания | То же: профиль остаётся вертикальным на наклонных участках |
| Ламели | Нулевая толщина = одна грань | То же, и ламели обрезаются по контуру непрямоугольной грани |
| Окна и двери | По одному проёму | В выбранный проём, а если выделить стену — во все её прямоугольные проёмы сразу |
| Отмена | Как получится | Каждое применение даёт ровно один шаг отмены, а отказ откатывает всё |
| Языки | Английский | Русский и английский пакеты |

Из того, что известно об оригинале по открытым описаниям, повторено всё,
включая эскалатор из Pro-версии. Сознательные ограничения: вальма по
невыпуклому контуру (Г-, Т-образные здания) не строится — такое здание
разбивается на выпуклые части; у винтовой лестницы нет встроенного
ограждения — его можно провести инструментом «Ограждение по рёбрам».

## Установка

Расширения → Менеджер расширений → Установить расширение →
`architools-0.2.0-rus.rbz` (или `-eng.rbz`). После установки или обновления
перезапустите SketchUp — меню и панель инструментов строятся при запуске.

Для разработки: `powershell -ExecutionPolicy Bypass -File dev_install.ps1`
копирует `src\` в Plugins SketchUp 2024 (`-Version 2025` — в другую версию).

## Структура

```
src/architools.rb                регистратор (SketchupExtension)
src/architools/
  main.rb                        меню, панель инструментов, запуск из меню
  constants.rb lang.rb           версия, категории; словари ru/en
  registry.rb                    каталог инструментов, параметры, запуск, настройки
  geom.rb                        цепочки рёбер, оси грани, сечения, коробки, сдвиг вершин
  profiles.rb                    библиотека сечений и проводка сечения по пути
  skeleton.rb                    прямой скелет выпуклого контура (вальма)
  place_tool.rb                  расстановка кликом
  panel.rb about.rb icons.rb     окна и иконки
  tools/edges.rb modify.rb walls.rb facade.rb railing.rb stairs.rb framing.rb
  html/                          panel.html, about.html, ba.css, ba.js, i18n.js
  icons/                         SVG-иконки панели инструментов
tools/build_rbz.ps1              сборка пакетов
dev_install.ps1                  установка в SketchUp для разработки
test/                            живые тесты через MCP-мост и проверка словарей
```

Новый инструмент добавляется одним `Registry.define(:id, :category) { |p| … }.run { |ctx| … }`
и строками `tool_id` / `hint_id` / `p_…` в `lang.rb`. Панель и меню строятся
по каталогу сами.

## Сборка

```
powershell -ExecutionPolicy Bypass -File tools\build_rbz.ps1          # обе сборки
powershell -ExecutionPolicy Bypass -File tools\build_rbz.ps1 -Lang en # только английская
```

Пакеты появятся в `dist\architools-<версия>-rus.rbz` и `-eng.rbz`.

## Проверка

- `ruby test/check_lang.rb` проверяет офлайн, что у ru и en одинаковые ключи
  и что у всех инструментов, параметров и режимов есть подписи.
- `ruby test/check_skeleton.rb` проверяет офлайн прямой скелет кровли на
  шести контурах.
- `python test/bridge.py test/live_tools.rb` гоняет 96 проверок в живом
  SketchUp через MCP-мост (`127.0.0.1:8080`). Там у каждого из 33
  инструментов есть функциональная проверка, плюс отказ на пустом выделении,
  одна отмена на применение и контроль покрытия. Всё строится во временной
  группе-песочнице, и остальная модель не трогается. Протокол последнего
  прогона лежит в [docs/TESTING.md](docs/TESTING.md) и пересобирается
  командой `python test/make_report.py <вывод>`.
- `python test/bridge.py test/live_demo.rb` и `test/live_demo2.rb` строят
  демо-сцены и сохраняют снимки вида.
- После `dev_install.ps1` код перезагружается без перезапуска SketchUp:
  `python test/bridge.py test/reload.rb`.

## Грабли

- `Length#<` в SketchUp сравнивает с допуском 0,001″: `0.to_l < 0.0001`
  даёт `false`. Расстояния и длины векторов перед сравнением приводим к
  `Float`.
- `Entities#transform_by_vectors` неверно двигает вершины кривых (дуг,
  окружностей): кривые распускаются, сдвиг идёт, потом они свариваются
  обратно (`Geom3.move_vertices`).
- `add_line` не режет встречные рёбра. Поэтому сетку на грани рисуем
  отрезками между пересечениями, иначе грань не разделится.
- Неплоский многоугольник `PolygonMesh` SketchUp молча выбрасывает, и в теле
  остаётся дыра. Перед `fill_from_mesh` такие многоугольники
  триангулируются.
- Скругление сначала строит дугу, а уже потом удаляет угловые куски. Тогда
  исходная грань сохраняется, а отваливается только уголок.
- `add_face` поверх грани стены может развернуть её остаток изнанкой
  наружу. После пробивки проёма нормали этой плоскости возвращаются.
- Внутри открытой группы координаты в Ruby API мировые: чтение и запись в
  активном контексте согласованы, но трансформация группы на них не влияет.
